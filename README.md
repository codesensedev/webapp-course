# Web app course

Learn HTML, CSS and JavaScript by building a small web app.

## What you need

- VS Code, with the Live Server extension
- Chrome or Edge
- Git
- A GitHub account

## Get the course

Open a terminal in the folder where you keep your projects, and run:

```
git clone https://github.com/learnshelf/webapp-course.git
```

If it asks you to sign in to GitHub, sign in with your account.

This makes a folder called `webapp-course`. Open it in VS Code. To read a lesson nicely, open its file and press `Ctrl+Shift+V` (`Cmd+Shift+V` on a Mac).

To get new content:

```
cd webapp-course
git pull
```

## Keep the course and your project apart

```
  Projects/
    ...
    webapp-course/     this course: read it and pull it, but do not change it
    ...
    my-webapp/         your project, name folder as you want
    ...
```

Keep VS Code on one side of the screen and the lesson on the other.

## Open your page with Live Server

Install Live Server once in VS Code:

1. Click the **Extensions** icon on the left side of VS Code, or press `Ctrl+Shift+X` (`Cmd+Shift+X` on a Mac).
2. Search for **Live Server** by Ritwick Dey and click **Install**.

To open your page:

1. In VS Code, open your project folder, such as `studentplanner`.
2. Open its `index.html` file.
3. Click **Go Live** at the bottom right of the VS Code window. Your browser will open the page.

When you save changes to your files, Live Server refreshes the page in the browser. If you do not see **Go Live**, check that Live Server is installed and that `index.html` is open.
